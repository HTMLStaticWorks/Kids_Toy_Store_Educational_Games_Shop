# Kids Toy Store & Educational Games Shop HTML Template

A commercial-grade, responsive, ThemeForest-ready static eCommerce HTML5/CSS3/Vanilla JS template tailored for Kids Toy Retailers, STEM Learning Shops, Baby Stores, and Educational Game Boutiques.

## 🌟 Key Features

- **Design System**: Playful & Premium UI/UX featuring custom color palettes (Bright Blue `#2563EB`, Playful Pink `#EC4899`, Sunny Yellow `#FBBF24`, Fresh Green `#22C55E`), Poppins + Inter + Nunito Sans typography, and Glassmorphism accents.
- **Light & Dark Mode**: Persistent theme switcher powered by `localStorage` and `data-theme` attributes with high-contrast dark theme styling (`#0F172A`).
- **Complete Page Set (15 Pages)**:
  1. `index.html` — Homepage 1 (Primary Retail Showcase)
  2. `home-2.html` — Homepage 2 (Educational Boutique & Interactive Toy Finder)
  3. `shop.html` — Product Catalog with sidebar filters (Age Group, Category, Educational Skill, Price Range, Brand)
  4. `product-details.html` — Product details with multi-image gallery, age recommendation badge, educational benefits, safety certifications, and reviews tab.
  5. `gift-guide.html` — Seasonal & occasion gift guide (Birthday, Christmas, Back-to-School, Budget under $25/$50/$100+)
  6. `featured-brands.html` — Brand showcase for Lego STEM, Melissa & Doug, NatGeo Kids, Hape, Ravensburger, Learning Resources.
  7. `wishlist.html` — Interactive wishlist manager with move-to-cart and share list UI.
  8. `cart.html` — Shopping cart with item quantity controls, subtotal calculator, and coupon handler.
  9. `checkout.html` — 3-step checkout UI (Billing/Shipping, Gift Wrap note option, Payment method selection).
  10. `blog.html` — Parenting & educational blog grid.
  11. `blog-details.html` — Full blog article page with author bio and comment section.
  12. `contact.html` — Contact inquiry form, store locator, operating hours, and instant WhatsApp support UI.
  13. `login.html` — Glassmorphism user login page.
  14. `signup.html` — User registration page with role selection (Parent / Teacher / Gift Shopper) and password strength meter.
  15. `404.html` — Playful 404 error page.

## 🛠️ Tech Stack & Dependencies

- **HTML5 & CSS3**: Custom CSS Properties, Flexbox & Grid layouts.
- **Bootstrap 5**: Grid layout & responsive utilities (`bootstrap.min.css`).
- **Vanilla JavaScript**: Zero heavy framework overhead.
- **GSAP 3**: Micro-animations, floating elements, counter triggers, and scroll reveals (`animations.js`).
- **Font Awesome 6**: Vector icons for cart, wishlist, star ratings, and age pills.
- **Unsplash Photography**: High-resolution, royalty-free local toy and child photography.

## 🚀 How to Run Locally

1. Clone or extract the repository folder into your workspace.
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
3. No build tools or Node server required!
